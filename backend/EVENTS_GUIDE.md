# 财经事件数据使用指南

本系统采用**半自动化**方式管理财经事件数据。

## 数据来源

### 1. 自动获取（AKShare API）
以下类型的事件会自动从AKShare获取，无需手动维护：

- **美联储利率决议** (`us_rate`)
  - 来源：`ak.macro_bank_usa_interest_rate()`
  - 包括：加息、降息、维持利率不变
  - 自动计算变动幅度和影响程度

- **中国央行降准** (`cn_rrr`)
  - 来源：`ak.macro_china_rrr()`
  - 包括：全面降准、定向降准
  - 自动提取降准幅度

### 2. 手动维护（编辑 events_data.py）
以下类型的事件需要手动添加到 `MANUAL_EVENTS` 列表：

- **美国大选** (`us_election`)
  - 总统大选、中期选举等

- **全球重大事件** (`global`)
  - 如：疫情、战争、金融危机等

- **其他重要事件**
  - 无法从API自动获取的特殊事件

## 如何添加新的手动事件

编辑文件：`backend/events_data.py`

在 `MANUAL_EVENTS` 列表中添加新事件：

```python
MANUAL_EVENTS = [
    # 政治事件
    {'date': '2024-11-05', 'name': '美国总统大选', 'type': 'us_election', 'impact': 'high'},

    # 添加新事件（例如）
    {'date': '2028-11-07', 'name': '美国总统大选', 'type': 'us_election', 'impact': 'high'},
    {'date': '2025-01-20', 'name': '美国总统就职典礼', 'type': 'us_election', 'impact': 'medium'},

    # 全球重大事件
    {'date': '2020-03-11', 'name': 'WHO宣布COVID-19全球大流行', 'type': 'global', 'impact': 'high'},
]
```

### 字段说明

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `date` | 字符串 | 事件日期 | `'2024-11-05'` |
| `name` | 字符串 | 事件名称 | `'美国总统大选'` |
| `type` | 字符串 | 事件类型（见下表） | `'us_election'` |
| `impact` | 字符串 | 影响程度 | `'high'` / `'medium'` / `'low'` |

### 事件类型 (type)

| 类型 | 说明 | 颜色 | 图标 | 自动/手动 |
|------|------|------|------|-----------|
| `us_election` | 美国大选 | 红色 | 菱形 | 手动 |
| `us_rate` | 美联储利率 | 蓝色 | 三角形 | **自动** |
| `cn_rate` | 中国降息 | 绿色 | 圆形 | 手动* |
| `cn_rrr` | 中国降准 | 深绿色 | 矩形 | **自动** |
| `global` | 全球事件 | 紫色 | 图钉 | 手动 |

*注：中国降息目前需要手动添加，未来可能会集成API。

### 影响程度 (impact)

- `high`: 重大影响（如：加息75基点、总统大选）
- `medium`: 中等影响（如：维持利率不变、小幅降准）
- `low`: 较小影响（较少使用）

## 缓存机制

- 事件数据会缓存**1小时**
- 避免频繁调用AKShare API
- 缓存在应用内存中，重启后自动刷新

## 数据更新频率

### 自动数据
- 首次访问时从AKShare获取
- 之后每小时自动刷新一次
- 服务器重启时重新获取

### 手动数据
- 编辑 `events_data.py` 后需要重启服务器
- 建议定期添加即将到来的重要事件

## 示例：添加2025年重要事件

```python
MANUAL_EVENTS = [
    # 现有事件...

    # 2025年新增事件
    {'date': '2025-01-20', 'name': '美国新总统就职', 'type': 'us_election', 'impact': 'high'},
    {'date': '2025-06-01', 'name': '某重大国际峰会', 'type': 'global', 'impact': 'medium'},
]
```

## 常见问题

**Q: 为什么我添加的事件没有显示？**
- 确认事件日期在图表的时间范围内
- 检查事件格式是否正确
- 重启Flask服务器

**Q: 如何查看自动获取了哪些事件？**
- 查看服务器启动日志，会输出获取的事件数量
- 打开浏览器控制台，查看图表渲染时的事件数据

**Q: 可以禁用自动获取吗？**
- 可以修改 `get_all_events()` 函数，注释掉相关的获取代码

**Q: 自动获取失败怎么办？**
- 系统会自动降级到手动数据
- 检查网络连接和AKShare版本
- 查看服务器错误日志

## 技术细节

- 文件位置：`backend/events_data.py`
- 主函数：`get_events_in_range(start_date, end_date)`
- 缓存变量：`_events_cache`
- 去重逻辑：基于 `(日期, 类型)` 组合

## 维护建议

1. **定期检查**：每季度检查一次即将到来的重要事件
2. **及时更新**：重大事件发生后及时添加到手动列表
3. **保持简洁**：只添加对股市有显著影响的事件
4. **测试验证**：添加后在图表上验证显示效果
